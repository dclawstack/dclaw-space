- CTA buttons: `rounded-pill` (999px), primary color

## Architecture Rules (from AGENTS.md — non-negotiable)

1. All models inherit from `Base` in `app.models.base`
2. All models use `Mapped[T]` + `mapped_column()` (SQLAlchemy 2.0 style)
3. **Never `default_factory=`** in `mapped_column()` — use `default=callable`
4. **Never timezone-aware datetime** — use `utc_now()` from `app.core.utils`
5. Repository pattern for ALL DB access — never raw session in routes
6. `pytest-asyncio==0.24.0` pinned — do not upgrade
7. No SQLite — PostgreSQL only (`postgresql+asyncpg://`)
8. All new tables need Alembic migrations
9. `ondelete="CASCADE"` for child tables
